# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| main    | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability, buffer overrun, or memory safety defect in aether-dsp:

1. **Do not open a public issue.**
2. Report the vulnerability privately through [GitHub Security Advisories](https://github.com/negg0s/aether-dsp/security/advisories/new).
3. If GitHub Advisories are unavailable, contact the maintainer directly via GitHub contact channels.

### Please Provide:
- A description of the issue and potential impact.
- Affected commit, component, or preset.
- Reproducible steps, test input, or audio file triggering the issue.
- Operating system and compiler details.

### Response Timeline
- Initial acknowledgment within 48 hours.
- Status update and patch evaluation within 7 days.
- Public release published after a fix is verified.
